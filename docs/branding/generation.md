# 铜色八向线标

根据用户提供的参考图片，使用 image_gen 生成高清版本，保留八向交叉线条与铜色配色，采用暖白背景。经人工查看后使用 Sharp Lanczos3 重采样导出 PNG。

- `docs/branding/logo-master.png`：1024 × 1024 的设计母版，仅用于设计维护，不作为网页静态资源发布。
- `public/assets/home/images/branding/favicon-32x32.png`：32 × 32，网页图标。
- `public/assets/home/images/branding/favicon-96x96.png`：96 × 96，页面品牌图标。
- `public/assets/home/images/branding/favicon-180x180.png`：180 × 180，Apple touch icon。

旧版品牌图片保存在 data/archive/branding-backup-before-copper/。
