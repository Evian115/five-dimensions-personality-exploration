## 32 项自动测试覆盖

- 草稿：部分与完整草稿恢复、原答案格式迁移、提交编号跨刷新保留、明确重开、成功清理和坏数据处理。
- 计分：反向计分、0–100 归一化、中点、极值、30 个细分维度和上游 reducer 一致性。
- 题库：60 题构成、来源不变、连续编号、正反向题与细分维度覆盖。
- 加密：60/120/50 题版本、密文长度、篡改、截断、错误密钥、密钥重启持久性。
- 记录：自增 ID、独立提交分别记录、原结构迁移、迁移备份可读且内容保留。
- 重试：响应丢失后重试、服务重启后重试、UUID 大小写规范化、同编号不同答案冲突、结果与回执写入失败时一起回滚。
- HTTP：同一提交并发重试、解密 GET/POST、响应长度、缓存策略、旧路由查询参数保留、解密不增加记录。

## 真实浏览器主流程

使用当前生产构建启动独立测试服务器，执行了以下操作：

1. 首页维度切换，点击开始进入作答页；未选择答案时下一题显示必答提示。
2. 实际逐题完成 60 题；答完前 5 题刷新，恢复到第 6 题；答完 60 题但未提交时刷新，保留全部答案和原提交编号，停在第 60 题。
3. 拦截一次提交：先让后端成功写入，再向浏览器模拟网络失败。刷新并重试后展示结果、清除成功草稿，数据库只保留一条记录。
4. 全选中立时五维分数均为 50；结果页可刷新并重新解密展示。
5. 分享弹窗、复制完整链接、取消重测、确认重测、随机跳过、无效密文提示和回到作答页均正常。
6. 375px 移动视口中可选择答案并切换题目，页面没有横向溢出。

浏览器没有未捕获的 JavaScript 错误。测试结束时，隔离库恰好有两条独立测评记录：完整作答一条、随机跳过一条；模拟丢失响应后的重试没有产生额外记录。

分享复制分别验证了 Clipboard API 路径和选择文本的兼容路径，测试中替换了实际剪贴板写入以避免覆盖用户剪贴板。因此本次验证的是页面调用和完整链接内容，没有验证操作系统剪贴板读回。

## 15 项额外接口检查

- Content-Type 错误 → 415。
- JSON 损坏、缺少答案、UUID 无效、分数越界 → 400。
- 量表版本过旧 → 409。
- 请求体超过限制 → 413。
- 未知 API、找不到的旧结果编号 → 404。
- 无效密文 → 400。
- 静态页面不支持的方法 → 405。
- 首页、作答页、带结尾斜杠的作答页、结果页 HEAD 请求 → 200 且无响应体。
